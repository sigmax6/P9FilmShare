P9FilmShare

老安卓手机 ⇄ 鸿蒙 / 卓易通 · 胶片传照片

一个 APK 同时充当发送端与接收端，让华为 P9（EMUI 4 / Android 6）以近乎“华为分享”的体验， 向鸿蒙设备批量传照片——免流量、免账号、不依赖厂商私有协议。

// 02工作原理

鸿蒙端当“热点主机 + 上传接收端”，老手机当“客户端 + 上传者”
1
鸿蒙设备（卓易通内运行） 开个人热点（SSID/密码可改）→ 起前台 HTTP 上传服务（8421）→ 生成二维码 P9SHARE2|ssid|pass|ip|port|token
↓
2
老安卓手机 扫码 相机扫二维码 → 自动连上热点（addNetwork + enableNetwork）→ 弹出相册批量勾选
↓
3
逐张上传 P9Client 用 HTTP POST 原图字节传到鸿蒙端；增量传输：已传过的默认不再传
↓
4
落盘图库 鸿蒙端写入系统图库「华为分享」相册；卓易通“文件互通”可直达宿主图库。重复照片弹「覆盖/复制/跳过」

设计要点：不用 Wi‑Fi 直连（EMUI 4 上 createGroup 必返 BUSY）；所有请求都是出站，天然穿透卓易通 NAT。

// 03构建

标准 Android Gradle 工程 · 仅依赖 ZXing core，无其他第三方库
# 克隆后构建 debug 包
git clone <your-fork-url> P9FilmShare
cd P9FilmShare
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug

# 产物
app/build/outputs/apk/debug/app-debug.apk

# 配置：AGP 7.4.2 / compileSdk 33 / minSdk 23 / targetSdk 30
# 依赖：com.google.zxing:core:3.3.3（务必锁 3.3.3，见 README 兼容性说明）
